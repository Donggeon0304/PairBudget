PairBudget 개인정보 처리방침

시행일: 2026년 10월 7일

PairBudget(이하 "앱")은 사용자의 개인정보를 중요시하며, 「개인정보 보호법」 등 관련 법령을 준수합니다. 본 방침은 앱이 수집하는 정보, 이용 목적, 보호 조치에 대해 안내합니다.

1. 수집하는 개인정보

1-1. 회원 가입 시

  • 이메일 주소, 비밀번호 (이메일 가입 시)
  • Google 계정 정보 (Google 로그인 시: 이메일, 이름, 프로필 사진)

1-2. 서비스 이용 시

  • 거래 내역 정보 (금액, 가맹점, 카테고리, 메모)
  • 금융 앱 알림 내용 (알림 접근 권한 허용 시)
  • SMS 문자 내용 (SMS 권한 허용 시, 금융 문자만 분석)
💡 알림 및 SMS 데이터는 금융 거래 정보 추출 목적으로만 사용되며, 외부 서버로 전송되지 않습니다. 모든 분석은 사용자 기기 내에서만 이루어집니다.

2. 개인정보의 이용 목적

  • 가계부 서비스 제공 (거래 기록, 통계 분석)
  • 커플/공동 가계부 기능 (상대방과 거래 내역 공유)
  • 금융 알림 자동 파싱 (수동 입력 부담 감소)
  • 앱 업데이트 알림

3. 개인정보의 보관 및 파기

  • 거래 내역: Firebase 서버에 암호화 저장, 회원 탈퇴 시 삭제
  • 알림 아카이브: 기기 내 암호화 저장, 30일 후 자동 삭제
  • 대기 거래: 기기 내 암호화 저장, 승인/거절 시 삭제
  • 학습된 카테고리: 기기 내 암호화 저장, 앱 삭제 시 파기

4. 개인정보의 제3자 제공

앱은 사용자의 개인정보를 제3자에게 제공하지 않습니다. 단, 커플 가계부 기능 사용 시 상대방에게 공동 거래 내역이 공유됩니다.

5. 개인정보 보호 조치

  • 기기 내 데이터: Android EncryptedStorage (AES-256) 암호화 저장
  • 서버 데이터: Firebase(Google Cloud) 암호화 저장 및 전송 (TLS)
  • 접근 제어: Firebase 보안 규칙으로 본인/가구 멤버만 데이터 접근 가능
  • 인증: Firebase Authentication (이메일/비밀번호, Google OAuth)

6. 사용자 권리

  • 개인정보 열람, 수정, 삭제 요청 가능
  • 회원 탈퇴 시 모든 개인 데이터 삭제
  • 알림/SMS 권한은 언제든지 기기 설정에서 해제 가능

7. 앱에서 사용하는 권한

  • 알림 접근 (NotificationListenerService): 금융 앱 알림에서 거래 정보를 자동 추출
  • SMS 읽기/수신: 금융 문자에서 거래 정보를 자동 추출
  • 인터넷: Firebase 서버와 데이터 동기화
